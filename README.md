# FTLabs 홈페이지 (ftlabs.kr)

기반기술 연구소(FTLabs) 공식 홈페이지. GitHub Pages로 `ftlabs.kr`에 서비스합니다.

- `index.html` — 본편(폰트·로고·아이콘 인라인 단일 완결본)
- `assets/` — 공유 카드(OG) 이미지, 파비콘, 애플 터치 아이콘
- `CNAME` — 사용자 도메인 `ftlabs.kr`
- `robots.txt`, `sitemap.xml` — 검색엔진 안내

원본 소스와 빌드 스크립트는 운영 워크스페이스(`work/ftlabs-site/`)에 있습니다.
